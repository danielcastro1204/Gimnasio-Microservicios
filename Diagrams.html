4. Diagrama de Secuencia (Comportamiento Dinámico)

Vista dinámica: Flujo de peticiones HTTP/REST y validación sincrónica entre microservicios.

                sequenceDiagram
                    autonumber
                    actor Cliente
                    participant MS as Class Service
                    participant TS as Trainer Service
                    participant DB as classdb

                    Cliente->>MS: POST /api/classes
                    MS->>TS: GET /api/trainers/{id}/exists

                    alt Trainer exists
                        TS-->>MS: 200 OK
                        MS->>DB: save(newClass)
                        DB-->>MS: entity saved
                        MS-->>Cliente: 201 Created
                    else Trainer missing
                        TS-->>MS: 404 Not Found
                        MS-->>Cliente: 400 Bad Request
                    end
